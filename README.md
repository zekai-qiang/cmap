# Human Compound Muscle Action Potential Analysis

This repository contains the R code for the human studies analysis described in: McKinnon, S., Qiang, Z., Keerie, A., Wells, T., Shaw, P. J., Alix, J. J. P., & Mead, R. J. (2025). Maximizing the translational potential of neurophysiology in amyotrophic lateral sclerosis: a study on compound muscle action potentials. Amyotrophic Lateral Sclerosis and Frontotemporal Degeneration, 26(3–4), 322–330. https://doi.org/10.1080/21678421.2024.2448540
